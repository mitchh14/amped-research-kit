# amped-research-kit
ARK is an open source Claude skills kit for UX and market researchers. Plug in ready-made research workflows, tune them to your team, and contribute back what you build. Built by researchers for researchers (and PwDR).

## Structure

```
amped-research-kit/
├── skills/       # Research workflow skills
├── docs/         # Documentation
└── examples/     # Example configurations
```

## Quick Start

Browse `/skills` for available research workflows. Each skill is designed to work with Claude Code and other AI tools.

## Contributing

Built for the research community. Contribute your workflows and help improve research practices.
